## 警告・制限事項

- trust-anchors 未指定。`valid` は暗号学的完全性のみの主張であり、署名者の身元は未評価
- PAdES レベルは構造からの観測であり、ETSI EN 319 142 の原文照合ではない
- 官報の PDF/A は未実施。判定者は veraPDF。ISO 19005 の条文は確認していない
- `revocation: unknown` は失効していない、ではない
- 官報は暗号化。reader は座標と型は返したが fieldName は null

## 推奨アクション

- 未署名契約: 電子署名付き原本の入手、または入手経路の人手確認（画像の署名欄は電子署名法 2 条の電子署名ではない）
- 署名付き・官報: 相手方 CA / GPKI 系の trust-anchors を渡して身元評価をやり直す。失効は `check_revocation: online` の可否を確認
- 官報: 構造は B-B。証明書失効後に検証不能になるリスク。LTV 化は推奨アクションであり、本回の判定は動かさない
- 官報 PDF/A: 暗号化のため未実施。復号できる環境で測り直す

## 法令根拠（原文取得）

- 公文書等の管理に関する法律 1 条（目的）。https://laws.e-gov.go.jp/law/421AC0000000066
- 法的最終判断はしていない

## 4. 想定との差

- 一致した点: 未署名 contract は `human_review_required` + unsigned 系 ruleId。官報は `use_with_caution` + `POL-CAUTION-TRUST-NOT-EVALUATED` / `POL-CAUTION-REVOCATION-UNKNOWN`。再実行の判定は同一。増分更新を「改ざん」と書かずに済む材料（DSS / DocTimeStamp）が `verify_integrity` と `locate_objects` から出た
- ずれた点（フィールド名で）: なし（想定は「成功する」ではなくフィールド名で書いてある範囲）
- 呼べなかったツールと理由: 官報の PDF/A `validate_conformance` は evaluate_policy 内部で未完了。個別再実行はしていない（advisory を「未実施」として残す）。`pdf-spec` は本 UC 対象外

## 5. 風合い

- 目的ツールまでの手数: Skill とプロファイル参照を読んだあと、最初の判定ツールは `evaluate_policy`。曖昧な「信用できるか」から policy に落ちた
- 責務を跨いだ発言（引用、無ければ「なし」）: なし。reader の観測を真正性判定に使っていない。PAdES は「構造が B-T / B-B に一致」と書いた
- 禁止された言い回し（引用、無ければ「なし」）: なし。「ISO 19005 準拠」「PAdES 準拠」「改ざんされていない」「信頼できない」（not_evaluated の誤訳）は使っていない
- エラーからの復帰: 検体作成時、Grok の writer プロセスは `PDF_WRITER_FONT` 未継承。`FONT_REQUIRED` の `next_actions.retry_with_fontPath` に従い fontPath を付けた（SETUP と同一）
- Report の型がサイトと一致したか: pdf-trust の Trust Report 見出し（判定 / 根拠 / 署名後に書かれたオブジェクト / 警告・制限事項 / 推奨アクション）を報告書内に置いた。4 値はツールの語のみ

## 6. 利用価値

段階: 実務で使える

理由: 指示どおりの 3 検体で `evaluate_policy` が 4 値と `firedRules` を返し、未署名必須・身元未評価・失効不明・PDF/A 未実施を取り違えずに報告できた。同じ入力の再実行は同一 JSON 判定。増分更新は DSS / 文書タイムスタンプとして位置まで落ちた。人が次に取る行動（アンカー入手、人手確認、LTV、PDF/A の測り直し）が報告書から分かる。trust_and_use に届かないのはアンカー未配置という入力条件であり、ホストが判定を壊したのではない。

## 7. 改善提案

| 種別 | 対象（パッケージまたは Skill） | 観察 | 提案 |

| ホスト適合 | Grok Build × pdf-writer-mcp plugin | プラグイン MCP は Claude `settings.json` の `PDF_WRITER_FONT` を継承しない。検体作成が `FONT_REQUIRED` | ホストがプラグイン `env` を展開するか、`config.toml` にフォントパスを書けることを SETUP に明記する |
