## 3. 成果物

- 出力 PDF: 無し（編集していない。SIGNED_PDF で停止）
- Report:

### このホストで測れたこと

- ページ数 1、署名あり、空パスワードで認証できた（evaluate_policy.scope.authenticated=true）
- Signature1 の暗号学的検証は valid。身元 not_evaluated。失効 unknown。DocTS `e-timing EVIDENCE3161_1` は valid
- PAdES 構造は Signature1=B-B（T3 の観察。準拠とは書かない）
- テキストは not_extractable（CMap）。空抽出を「テキストが無い」とはしない
- writer は署名を壊す書き換えを SIGNED_PDF で止めた
- **0.26.1**: auto の `validate_conformance` は INTERNAL_ERROR ではなく **ENCRYPTED_PDF**。veraPDF は走っていない
- native サブセットは暗号化を **no-encryption**（ISO 19005-1, 6.1.3）として fail した。認証ではない。authoritativeValidation.performed=false

### このホストで測れなかったこと（未実施）

- PDF/A-3b の veraPDF 採点: ENCRYPTED_PDF で拒否。**未実施**。passed にしない。compliant true ではない
- 本文の Unicode 抽出: not_extractable。render_page は本 UC では未実施（UC07 で PDFium は動くことを確認済み）
- writer の ENCRYPTED_PDF コード: 本検体では SIGNED_PDF が先。暗号化専用の writer エラーは未観測

## 4. 想定との差

- 一致した点: PDF/A（veraPDF）を passed にしていない。一部読めたを問題なしに伸ばしていない。evaluate_policy の advisory も「not performed」。**#38 / 0.26.1 で auto 経路の code が ENCRYPTED_PDF になった**
- ずれた点（フィールド名で）: writer は ENCRYPTED_PDF ではなく SIGNED_PDF。reader は鍵なしで止まらず、抽出可能性が not_extractable
- 呼べなかったツール: なし

## 5. 風合い

- 目的ツールまでの手数: inspect → summarize → metadata → evaluate_policy → validate_conformance auto → native → set_metadata。途中で「読めた」を合格にしていない
- 責務を跨いだ発言: なし
- 禁止された言い回し: なし。「ISO 19005 準拠」とは書いていない。native の compliant=false を規格全体の不適合証明とは書いていない。revocation unknown を失効していない、とは書いていない
- エラーからの復帰: ENCRYPTED_PDF の suggestion で native を一度見た。SIGNED_PDF では停止（無理に復号しない）
- Report の型: 測れたこと / 測れなかったことの 2 段

## 6. 利用価値

段階: 条件付きで使える

理由: PDF/A の未実施は 0.26.1 で **ENCRYPTED_PDF** として切れる。0.26.0 の INTERNAL_ERROR より、人が「採点していない」と読める。残る条件は writer の ENCRYPTED_PDF が署名付き検体では観測できないこと。
