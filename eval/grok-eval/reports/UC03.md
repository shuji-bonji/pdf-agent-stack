## 1. 目的と入力

10 年残す請求書を PDF/A-3b で作り、受け取り側で長期検証の構造を見る。CSV 付きで「PDF/A-4 で保存して」と頼まれたときは `pdfa-4` ではなく `pdfa-4f` を使う。ensure_pdfa はラベル。PAdES は構造の観測（T3）。

## 2. 実行ログ

| ステップ | 入力（ツール名と主パラメータ） | 想定 | 実際 |
| --- | --- | --- | --- |
| 1 | UC02 の `validate_conformance` flavour=pdfa-3b | COMPLIANT または違反リスト | 再測せず UC02 を流用。`engine=verapdf` `compliant=true` 146/146 |
| 2 | 依頼「PDF/A-4 で保存して。CSV は付けたまま」 | `pdfa-4f` を選ぶ | **選んだ flavour は `pdfa-4f`**（素の `pdfa-4` は添付自身が PDF/A であることを要求する）。`ensure_pdfa` flavour=pdfa-4f |
| 3 | `validate_conformance` flavour=pdfa-4f | veraPDF の点数 | `compliant: true` `checkedRules: 109` `passedRules: 109` |
| 4 | `create_text_pdf` ASCII、fontPath 無し | Helvetica | `font: Helvetica` |
| 5 | `ensure_pdfa` pdfa-3b on no-embed | ラベル + warning。declarationRisks | FONT_NOT_EMBEDDED Helvetica。CLAIMS warning |
| 6 | `identify_conformance` no-embed-claim-pdfa | 宣言 3b | `pdfA.part=3` `conformance=B` |
| 7 | `validate_conformance` pdfa-3b same file | 落ちることがある | `compliant: false` 145/146。violation `ISO 19005-3:2012 6.2.11.4.1-1` フォント未埋め込み |
| 8 | `detect_pades_level` 官報 / 自作 LTA / CRL 同梱 | サイト: B-B / B-T / B-LTA。T3 | 官報 Signature1 **B-B**（hasDocumentTimestamp true だが signature timestamp なし、DSS なし）。selfmade-pades-lta **B-T**（DSS あるが `revocationDataCoversSigner: false`、CRL 0）。selfmade-pades-crl **B-LTA**（CRL 1、coversSigner true） |

ツール JSON の要点:

```json
{
  "pdfa-4f-choice": "pdfa-4f (not pdfa-4) because CSV attachment",

    "selfmade-pades-lta": {"level": "B-T", "normativeBasis": "T3", "revocationDataCoversSigner": false},
    "selfmade-pades-crl": {"level": "B-LTA", "normativeBasis": "T3", "revocationDataCoversSigner": true, "dssCrlCount": 1}
  }
}
```

## 3. 成果物

- 出力 PDF: `out/publish-invoice.pdf`、`out/publish-invoice-pdfa4f.pdf`、`out/no-embed-claim-pdfa.pdf`
- Report 本文: 本ファイルの判定表が Publish / Trust 側の LTV 記録を兼ねる

## 4. 想定との差

- 一致した点: 3b+CSV は UC02 で COMPLIANT。A-4+CSV は 4f を選び 109/109。ラベル付き Helvetica は identify が 3b、validate が非 COMPLIANT。PAdES 3 検体はサイト実測と同じ B-B / B-T / B-LTA
- ずれた点: ファイル名 `selfmade-pades-lta.pdf` の構造は B-LTA ではなく B-T（失効データが署名者を覆わない）。これは検体の性質で、ツールの誤記ではない
- 呼べなかったツール: なし

## 5. 風合い

- 目的ツールまでの手数: ensure_pdfa の直後に validate_conformance。verify を飛ばしていない
- 責務を跨いだ発言: なし。「ISO 19005 準拠」「B-LTA 準拠」は使っていない。書いたのは「veraPDF が COMPLIANT と判定」「構造が B-LTA に一致する」
- 禁止された言い回し: なし
- エラーからの復帰: Helvetica は FONT_REQUIRED ではなく、ensure 後の declarationRisks と veraPDF 違反
- 「A-4 で」+ CSV: flavour を 4f に変えた（確認してから呼んだ）

## 6. 利用価値

段階: 実務で使える

理由: flavour 取り違えを避け、ラベルと採点の差（Helvetica）を隠さず、PAdES を T3 で書けた。人が 10 年残しの器として 3b か 4f かを選べる。

| 種別 | 対象 | 観察 | 提案 |

## 8. 再現手順（最短）

1. 添付付き請求を ensure_pdfa pdfa-3b → validate_conformance pdfa-3b
2. CSV 付きのまま「A-4」と言われたら **pdfa-4f** で ensure → validate
3. Helvetica の ASCII PDF に ensure_pdfa だけ掛け、identify と validate の差を書く
4. detect_pades_level。level / hasDss / revocationDataCoversSigner。準拠とは書かない
